# DNA الهندسي — مستفاد من تحليل zoih6/lamset-shifa (motion-doc-studio)

## لماذا كان عملنا «بسيطًا» — وما الذي يجعل عملهم متسقًا واحترافيًا

| البُعد | نهجهم (الاحترافي) | نهجي السابق (البسيط) |
|---|---|---|
| **العمود الفقري** | فكرة حاكمة واحدة تتحوّل عبر الفيلم (خطوة→نقطة→قوس→قرص→قزحية→شعار) — كل انتقال مورفينغ هندسي | مشاهد-بطاقات بريدية، كل مشهد جزيرة |
| **اللقطات** | سجل مركزي SHOTS؛ كل لقطة {a,b,draw,tin} والمحرك يختار ويحرك | if/else زمنية داخل مشهد واحد ضخم |
| **الانتقالات** | على مستوى المحرك TRANS (whip بضبابية 260px، iris بحافة ذهبية قائدة، band، zoom، dip) — يُرسم اللقطة القديمة في بفر ويُكشف الجديد | Whip يدوي داخل المشهد، غير قابل لإعادة الاستخدام |
| **الحركة** | 3 نوابض فيزيائية فقط {card 150/19, snap 320/28, pop} + مكتبة منحنيات مسماة (signature/camera/overshoot) + kf() | عشرات الـeasings العشوائية، بلا قواعد |
| **الكتابة** | KT: كلمة-كائن مرسومة مسبقًا + 23 دخولًا و12 خروجًا معياريًا + **كشيدة (تطويل) بدل تتبع الحروف** + خروج أقصر من الدخول دائمًا | كشف بمستطيلات، بدون خروج معياري |
| **الكاميرا** | سردية: تتبّع للعنصر الجديد ثم انسحاب (camS/camF عبر kf) | زوم خطي ممل في كل مكان |
| **الصوت** | إشارات مشتقة رياضيًا من نفس نوابض الصورة (when.spring → start/peak/land بالإطارات) — انحراف = صفر بالبناء | أزمنة تُكتب يدويًا (تنحرف) |
| **التوحيد البصري** | post لكل إطار: grain بنبض 12 + vignette + soft-light دافئ | فينييت متقطع فقط |
| **الجودة** | still.mjs إطار-تدقيق، cs.sh لوحات اتصال، qa JSON للمزج، release encode | ارتجال |
| **الإيقاع** | جديد كل 2–4ث، بطل hero واحد كل ~4ث (thump+tap + stop_before + بناء موسيقي) | بدون نبض أبطال |

## محرك نجوم v3 — ما سنبنيه (نفس الفلسفة، كودنا الخاص، أصولنا البصرية المُصادق عليها)
1. **core3.js**: سجل SHOTS + TRANS مضمّن (whip/iris-ذهبي/band/zoom/dip) + post موحّد (grain12+vignette+grade) + 3 نوابض فقط + kf().
2. **kt.js**: KT.word مرسوم مسبقًا (ذهب/كحلي) + IN/OUT معيارية (rise/pop/zoom/mask/wipe-rtl/grow ↔ lift/blur/push) + group stagger + كشيدة للتباعد + dot/leader/comet.
3. **kit_oct7.js**: حزمة الأكاديمية: اللوحة اللونية المقفلة، stage كحلي، gold3D (نصائح المعاينات)، plaque/medal/laurel/crown، قوس/شارة، غبار/أشعة، brand-iris بحافة ذهبية.
4. **الفكرة الحاكمة للفيلم**: «شرارة نجمة واحدة تتحوّل»: غبار → الشعار → نجمة الرقم 1 → **ميدالية كل طالب تنفتح كقزحية على عالمه** → كوكبة الأسماء 360° في الختام. كل انتقال = الشرارة تطير/تتحول.
5. **cues3.js**: cue.appear/move/hero/cut مع when.spring/ease (نفس الرياضيات)، يرفد make_audio.py.
6. **أدوات**: still إطار-تدقيق + contact-sheet تلقائي في render + release encode (-14 LUFS، crf21).
