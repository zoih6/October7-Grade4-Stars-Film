# ورقة الإنتاج التكيفية — «نجوم الصف الرابع» (مدرسة 7 أكتوبر)
> منهجية ai-film-studio v3.2.0 — M0 نية → M1 ورقة تكيفية → M4e حزمة مرجعية → أقفال النمط → بوابات الجودة.

## 1) النية الفنية (M0)
- **النوع:** فيلم قصير احتفالي سينمائي عمودي 1080×1920 — «مقطورة أوسمة» لأوائل الصف، ليس شرائح.
- **الإحساس:** فخر · هيبة · دفء · مستقبل مشرق.
- **المحرّك:** كود Canvas خالص من الزمن t، نبض 12fps بطوعية مع ضبابية حركة حقيقية (tmix من 24fps).

## 2) القفل الأسلوبي (Style Lock) — مُثبَّت حرفيًا
- **LOCK-F (فوتورياليستيك استوديو)** لكل الخلفيات: {PALETTE} = `deep royal navy #0A1931, cinematic midnight blue, royal gold #C9A86A, pearl white glow` + CLOSER: «cinematic lighting, defined key, soft fill, thin rim light, full-frame cinema camera, subtle film grain, rich contrast, no illustration, no stylization, no text».
- **تطوّر واحد مسموح:** فصل الأغنية يضيف تدرجات بنفسجي/سماوي احتفالية.
- **خطوط:** العناوين Cairo Black(1000) / Tajawal Black (3D ذهبي بإكستروجن كحلي)؛ الأسماء IBM Plex Sans Arabic Bold داخل لوحات-دروع؛ الشعر Rakkas؛ الكوفية NotoKufi.
- **نصوص تتكشّف حرفًا حرفًا:** نافذة كشف RTL تقدّمية + رأس ضوء (بدون تتبع حروف — يحافظ على الوصل).

## 3) الحزمة المرجعية (M4e)
- `preview-01/02/03.png` + `video-preview.mp4` (zoih6/preview-images): النظام البصري المُعتمد = شعار أكاديمي ذهبي، قاعة مكتبة بأعمدة نور، رقم «1» عملاق متوَّج على منصة، بطاقات طلاب بصور مقصوصة + إطارات ذهبية + لوحات أسماء + ميداليات ترتيب، خلفيات-عوالم لكل طالب (قمر/قلوب/شلال/حمام/بالونات/ورود/صاروخ/مكتبة).
